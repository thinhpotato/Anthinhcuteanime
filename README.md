# Website Tạp Hóa Bình Dân 

## Giới thiệu
Đây là bài tập xây dựng website tĩnh bán hàng tạp hóa bình dân bằng HTML5 và CSS3.

## Cấu trúc thư mục
- `index.html`: Trang chủ giới thiệu tiệm tạp hóa.
- `products.html`: Danh sách sản phẩm.
- `about.html`: Lịch sử cửa hàng.
- `contact.html`: Form gửi thông tin liên hệ.
- `css/style.css`: Tệp định dạng giao diện chung và Responsive.
- `images/`: Chứa hình ảnh minh họa cho website.

## Nguồn tài liệu & Hình ảnh
- Hình ảnh minh họa tải từ Unsplash,Pixels,Google Images
